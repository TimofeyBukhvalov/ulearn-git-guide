# C1. Минимальная конфигурация

## Первоначальная настройка

Для начала нужно задать базовые параметры пользователя Git. Без них Git не сможет корректно создавать коммиты.

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "your.email@example.com"
```

После этого можно проверить, что настройки применились:

```bash
git config --global --list
```

Полезно также настроить стандартное имя основной ветки и включить цветной вывод:

```bash
git config --global init.defaultBranch main
git config --global color.ui auto
```

Эти настройки достаточно для минимальной рабочей конфигурации Git. Дальше можно приступать к созданию репозитория и работе с коммитами.
